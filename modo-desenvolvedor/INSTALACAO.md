# Instalação do Modo Desenvolvedor

Siga o [tutorial completo do projeto](../INSTALACAO.md#10-opcional-instalar-o-botão-desenvolvimento). Ele inclui a ordem de build, assinatura, permissão de Acessibilidade, início automático e a integração opcional com a Echo.

Para usar somente o layout, compile e instale o aplicativo conforme a seção 10, sem configurar a Alexa. A integração só é executada quando há uma configuração privada habilitada.
